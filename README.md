# final-project
Everyone talks about branding these days. A crucial part of "branding" 
The goal of my code now is to act as a buzzfeed-like quiz that helps someone determine a unique, personal style based on a color palette that best complements their coloring, a jewelry type that suits their preferences and lifestyle, and a clothing type based on their personality and tastes. As the code instructs, you simply enter the number choice of the option for each question, and then you get your results based on your input at the end of the quiz!
